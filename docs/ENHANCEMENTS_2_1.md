# 2.1.0 기능과 사용 방법

2D(`com.traveler.next`)와 3D(`com.traveler.threed.next`)의 New 앱용 업데이트입니다. 같은 New 앱의 2.0.0 위에 설치하며 기존 앱을 지울 필요가 없습니다. 이 문서는 구현된 사용 방법을 설명합니다. 최종 APK 검증 결과는 배포 폴더의 검증 기록을 확인하세요.

## 백업·복원·휴지통

첫 화면의 **백업**에서 여러 여행을 선택해 사진 포함 ZIP을 폴더에 저장합니다. 한 여행마다 파일 하나가 생기며 완료된 여행에 최근 백업 날짜를 기록합니다. 사진을 읽지 못한 여행은 실패로 표시됩니다. 사진 접근 확인은 파일 연결 상태를 검사합니다. ZIP 백업·복원은 각 파일의 SHA-256과 ZIP CRC를 검사합니다.

JSON 또는 ZIP을 여러 개 선택하면 여행 제목·기간·미디어 수·사진 포함 여부를 먼저 표시합니다. 같은 제목·기간 또는 이전 복원 파일이 발견되면 기본 선택에서 제외합니다. 직접 선택하면 별도 여행으로 복원합니다. 같은 복원 작업의 재시작은 예약된 여행 ID를 재사용해 중복 생성하지 않습니다.

여행 삭제는 휴지통으로 이동합니다. 휴지통에서도 기록과 앱 보관 사진은 유지됩니다. 백업 화면에서 복원하거나 별도의 확인 후 영구 삭제할 수 있습니다. 앱 제거 시 앱 내부 데이터가 삭제되므로 외부 ZIP 백업은 별도로 보관하세요.

## 진행 중인 작업

첫 화면의 **작업**에서 백업·복원·사진 보관·사진 추가·영상 제작 진행 상황, 결과와 재시작을 확인합니다. 사용자가 시작한 작업은 foreground service에서 실행되므로 화면을 닫아도 계속됩니다. 알림 권한을 허용하면 알림에서도 진행 상황을 볼 수 있습니다.

강제 종료·운영체제 종료·시간 제한으로 중단될 수 있습니다. 다시 앱을 열고 작업에서 재시작하세요. 완료한 여행 단위 결과는 유지하며 영상은 처음부터 다시 제작합니다. 자동으로 무제한 재시도하지 않습니다. 개별 여행의 기존 보관·백업 화면에서 진행하는 작업은 해당 화면을 유지해야 합니다. 화면을 이동하려면 **다른 화면에서도 계속 보관** 또는 첫 화면의 백업 관리 기능을 사용하세요.

## 여행 생성 후 미디어 편집

여행의 사진 보관 화면에서 **사진 추가·날짜·장소·동영상 편집**을 엽니다. 선택한 파일은 앱에 복사합니다. 여행 기간 내 날짜와 방문지를 직접 배정할 수 있으며 원본 파일의 촬영 정보는 변경하지 않습니다. 확인할 수 없는 촬영 시각을 임의로 만들지 않습니다. 앱 보관본과 원본 연결을 구분해 표시합니다.

동영상의 **구간·소리**에서 사용할 구간과 원본 소리·해당 구간의 배경음악 음량을 정합니다. 일반적으로 3~10초이며 남은 원본이 짧으면 남은 길이까지만 사용합니다. 미리보기는 선택 구간을 재생합니다. 영상 제작에 선택된 동영상은 실제 프레임을 넣으며 원본 소리는 44.1 kHz 스테레오로 변환해 믹싱합니다. 파일에 오디오 트랙이 없으면 무음입니다. 원본 프레임은 최대 15 fps로 읽고 완성 영상은 30 fps로 저장합니다. 지원하지 않는 코덱은 작업 오류로 안내합니다.

구간 설정은 사진 포함 백업에도 보존됩니다. 날짜·방문지에 배정된 대표 미디어가 여행 영상에 선택될 수 있습니다. 완성 영상은 앱 내부에 보관되며 영상 제작 화면에서 갤러리에 저장하거나 공유할 수 있습니다.

## 3D 재생

3D 설정에 **자동 / 발열·배터리 절약 / 선명하게** 선택을 추가했습니다. 발열 감지와 시스템 절전 모드는 선명도 설정보다 우선하며 품질은 천천히 회복합니다. 절전 상태에서는 프레임 요청을 최대 약 20 fps로 제한합니다. 실제 프레임 속도·온도·배터리 사용량은 기기에 따라 달라집니다.

장면 경계에서 카메라 초점을 부드럽게 이동하고 지구 반대편으로 이동할 때도 구면 위에서 전환합니다. 경로와 여행자 위치 기록은 바꾸지 않습니다. 오프라인 준비 상태는 내장 기본 지도·다운로드한 지형·화면에서 저장한 도로 지도의 범위를 구분합니다. 도로 지도 전체를 일괄 다운로드하는 기능은 아닙니다.

## 업데이트

실행 시 새 버전을 확인하고 있으면 알립니다. 업데이트 창에서 **실행 시 Wi-Fi에서 새 버전 자동 받기**를 켜면 검증된 비과금 Wi-Fi에서 미리 받습니다. 이 옵션의 기본값은 꺼짐입니다. Wi-Fi 연결이 바뀌거나 앱 프로세스가 종료되면 다운로드가 중단될 수 있습니다. 완료된 파일은 재실행 시 복구하며 설치 직전에 서명·해시·앱 ID·버전을 다시 검사합니다.

설치는 Android 확인 화면에서 사용자가 진행합니다. 완전 무인 설치 기능은 제공하지 않습니다. APK와 `update-next.json`이 해당 앱의 정식 GitHub 릴리스에 게시되어야 실제 배포 알림이 동작합니다. 여행 기록과 사진을 업데이트 서버에 보내지 않습니다.
