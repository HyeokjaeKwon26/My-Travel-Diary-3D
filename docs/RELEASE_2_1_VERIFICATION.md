2026-10-29, Android 16 / API 36 x86_64 에뮬레이터에서 검사했습니다. 개인 휴대폰은 연결하지 않았으며 사진·동영상·여행 기록은 합성 테스트 자료를 사용했습니다.

## 최종 서명 APK

- New 2.0.0에서 New 2.1.0으로 덮어 설치했습니다. 기존 여행의 데이터베이스 행과 앱 보관 사진의 SHA-256을 비교해 모두 유지되는 것을 확인했습니다. 원래 `com.traveler`, `com.traveler.threed` 앱의 버전과 데이터도 유지됐습니다.
- 같은 사진 포함 ZIP을 두 앱의 복원 미리보기에서 열고, 사진 2개와 동영상 1개를 복원했습니다. 각 앱에서 3개 모두 읽기 가능·앱 보관 상태를 확인했습니다.
- 두 최종 APK에서 720p 여행 영상을 생성했습니다. 선택한 6초 구간의 빨간색→파란색 프레임 전환을 완성 영상에서 확인했습니다. 배경음악을 끈 상태에서 원본 테스트 톤을 디코딩했으며, 약 11.26초 MP4의 오디오 RMS는 두 앱 모두 약 0.0907이었습니다.
- 2D의 영상 작업을 실행 도중 강제 종료했습니다. 재실행 후 중단 상태를 표시했고, 재시작한 작업은 원래 작업 식별자를 유지하며 완료됐습니다. 두 앱의 통합 테스트에서도 Activity를 닫은 뒤 영상이 완료됐습니다.
- 2D의 백업 관리 화면에서 두 여행을 함께 외부 Documents 폴더에 저장했습니다. 여행별 ZIP 2개, 최근 백업 날짜, 미디어 수 2개·3개 및 각 파일의 SHA-256·ZIP CRC를 확인했습니다. 백업·복원 및 중복 방지의 공통 로직은 두 앱 통합 테스트에서 검증했습니다.

## 업데이트와 검증 범위

같은 New 앱 ID·서명 키와 더 큰 버전 코드를 사용합니다. 실행 시 확인, 선택형 Wi-Fi 다운로드, 서명·해시 검증 및 Android 설치 확인을 지원합니다. 공개 서버의 실제 업데이트 설치 결과는 각 릴리스에 첨부된 `VERIFICATION.md`와 함께 확인할 수 있습니다.

에뮬레이터 검증은 실제 휴대폰의 발열·배터리·장시간 프레임 속도나 모든 제조사 코덱의 동작을 보장하지 않습니다. 3D 카메라와 품질 제어의 수치 조건은 단위 테스트로 검사했고 실물 기기의 온도 측정은 하지 않았습니다. 자동 다운로드는 앱 실행 시 확인 과정에서 동작하며, 설치는 Android에서 사용자가 확인합니다.
