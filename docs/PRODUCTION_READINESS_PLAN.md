# My Travel Diary 3D — 완성품 전환 수정안

작성: 2026-09-15. 이번 요청의 산출물은 수정 계획 보고이며, 아래 기능은 구현 완료를 의미하지 않는다.

## 제품의 완료 기준

사용자는 Timeline과 사진을 가져오고 재생하면 된다. 지형 팩 파일을 찾거나 변환할 필요가 없어야 한다. 지원하는 지역에서 필요한 지형은 앱이 준비하고, 저장된 여행은 오프라인으로 다시 재생된다. 네트워크·저장 공간·고도 데이터가 부족할 때에도 설명 가능한 상태와 복구 방법을 제공한다. 기존 앱은 그대로 유지한다.

## 1. 여행에 맞춘 지형 자동 준비

- 고정된 그랜드캐년 JSON과 수동 팩 중심 흐름을 타일 기반 저장소로 교체한다. 수동 가져오기는 고급 설정에만 남긴다.
- 여행의 지상 이동 경로 및 카메라에 보일 주변 범위에서 필요한 타일을 계산한다. 방문지 두 곳을 감싸는 거대한 사각형이나 대륙 간 비행 전체를 고해상도로 받지 않는다. 비행은 저해상도 지구본을 사용한다.
- 작은 저해상도 지형을 우선 준비하고, 가까운 지상 구간부터 상세도를 높인다. 재생 중 갑자기 지형 높이가 바뀌지 않도록 준비된 장면으로 안전하게 전환한다.
- 기본 네트워크 정책은 Wi-Fi 자동 준비, 모바일 데이터는 예상 용량과 사용 선택을 제공한다. 새 지역을 데이터 없이 처음 여는 경우 정확한 상세 지형은 제공할 수 없으며, 기본 지도와 지형 미준비 상태를 표시한다.
- 다운로드 진행률/예상 용량, 취소·다시 받기·이어서 받기, 실패한 타일의 제한된 재시도 및 체크섬·형식 검사를 구현한다. 앱 재시작 후에도 상태를 복구한다.
- Android INTERNET/ACCESS_NETWORK_STATE 권한 및 용도 설명을 추가한다. 기존 “네트워크 권한 없는 100% 오프라인” 문구는 “여행 처리 로컬, 지형 준비 시 인터넷, 준비 후 오프라인 재생”으로 고친다.

공급 후보는 AWS에 공개된 Mapzen Terrain Tiles다. 공개 접근 가능 여부와 별개로 지역별 원자료의 이용·캐시·표시 조건, 출처 표기, 결측과 수직 기준을 확인한다. 공개 버킷을 서비스 가용성 보장으로 간주하지 않는다. 공급자 장애 시 저장된 자료와 기본 지도는 유지하고 새 지형 준비의 실패를 알린다. 미러/CDN이 필요하면 실제 배포량으로 운영 비용을 산정하며 무료·무제한을 약속하지 않는다.

원본 Timeline JSON과 사진을 지형 제공자에 업로드하지 않는다. 다만 타일 요청의 지역과 접속 IP가 제공자에 보일 수 있음을 안내한다.

## 2. 저장 용량과 메모리 제한

- 지역당 거대한 JSON 대신 압축된 높이 타일, 타일 색인, 버전·출처 정보를 저장한다. 같은 타일을 여러 여행에서 공유하고 참조 관계를 관리한다.
- 초기 정책안: 지형 저장 한도 기본 200 MB, 사용자 변경 가능. 이 수치는 데이터 용량 예측이나 성능 실측치가 아니다.
- 최근 사용하지 않은 임시 지형부터 삭제한다. “오프라인 유지”로 지정된 여행의 지형은 자동 삭제하지 않고, 한도를 넘기면 필요 용량과 상세도 변경/한도 변경 선택을 제공한다. 여행 원본·사진을 캐시 정리 대상으로 삼지 않는다.
- 디스크 캐시와 메모리 캐시를 분리하고 화면 주변 타일만 메모리에 올린다. 메모리 압박 시 상세도를 낮춘다.
- 기존 31 MB WAV를 압축 오디오로 교체하고 영상 인코더는 필요한 PCM 구간만 디코딩한다. 대형 시간대 데이터의 유지 필요성과 생명주기를 점검하고, release 코드 축소·불필요한 포함 자료 정리를 수행한다. 설치 크기는 실제 release APK로 보고한다.

## 3. 경로와 고도 신뢰성

- 파싱 → 정리 → 고도 준비 → 재생·카메라·영상의 공통 경로 결과를 버전 관리한다. 장소 이름/이동 수단 수정이나 재가져오기 시 관련 캐시를 갱신한다.
- 시간 중복과 공간 유사성을 함께 보고 중복 기록만 정리한다. 왕복, 헤어핀, 평행 도로, 재방문은 구별한다. 표시용 연결선을 되살리지 않는다.
- 실제 관측 시간 기준으로 비현실적 속도·GPS 점프·고도 급변을 탐지한다. 원본은 보존하며 원인·보정·신뢰도를 추적한다. 재생 배속을 실제 이동 속도로 오인하지 않는다.
- 결측 고도를 0 m로 바꾸어 순간 추락을 만들지 않는다. 지형 경계에서는 일관된 기준과 전환을 사용하고, 자료가 없거나 수직 기준이 다른 구간은 미상으로 처리한다.
- 다리·터널은 DEM만으로 도로 높이를 확정하지 않는다. 명확한 이상치만 고치고, 애매한 구간은 단순화된 전환과 표시를 사용하며 구간별 사용자 수정도 제공한다.
- 고도가 없는 비행의 표현용 곡선을 측정 고도로 표시하지 않는다.
- 사용자가 보고한 두 줄 현상은 해당 캡처와 구간을 받아 재현·수정 전후 비교로 확인한다. 실제 자료 없이 해결 완료로 보고하지 않는다.

## 4. 3D 재생 품질과 자동 성능 조절

- 타일별 상세도, 화면 밖 제외, 경계 이음 및 지면에 붙는 경로·차량을 구현한다. 제한된 영역의 메쉬만 비동기로 준비한다.
- 카메라는 지형 아래로 들어가지 않게 하고 급회전·정차·구간 전환·되감기에서도 부드럽고 결정적으로 계산한다. 차량 방향과 기울기를 완화하되 원래 이동 경로를 지우지 않는다.
- 상태를 공유하는 재생·탐색·영상 출력이 같은 본편 시점의 위치와 고도를 사용하도록 검증한다.
- 기본 30fps를 목표로 기기 부하·발열에 따라 내부 해상도와 지형 상세도를 자동 조절한다. 품질을 낮춰도 불안정하면 명시적으로 2D 전환을 제공한다.

## 5. 영상·권한·실패 복구

- 1080p/720p 선택, 코덱 기능 확인 및 지원되는 출력으로의 대안을 제공한다.
- 엔코더 EOS까지 제한된 시간 동안 배출하고, 완료되지 않은 영상을 성공으로 처리하지 않는다. 음악 길이·영상 길이·타임스탬프 및 최종 MP4 재생을 검증한다.
- 앱 백그라운드, 화면 회전, 취소, 저장 공간 부족, 권한 철회와 저장 실패를 지원 Android 버전에서 검증한다. 부분 파일과 미완료 갤러리 항목을 정리한다.
- 주소 일반화 옵션의 실제 범위를 설명하고 결과 미리보기를 제공한다. 사진 속 글자나 지도 경로까지 자동 익명화됐다고 표시하지 않는다.

## 6. 정식 배포 및 인수 검증

- 장기간 유지할 release 서명키를 안전하게 관리하고 서명된 정식 APK를 배포한다. 현재 debug 서명 알파에서 다른 서명키로 단순 덮어쓰기는 불가능하므로, 여행 내보내기/복원과 전환 안내를 먼저 준비한다. 자동 삭제나 무통보 재설치를 하지 않는다.
- Android 버전·메모리·GPU가 다른 대표 실기기 최소 3종에서 검증하고 지원 범위를 명시한다. 사용자 기기도 포함한다.
- 목표: 준비된 기준 여행의 재생 시작 3초 이내, 표준 품질 30fps에 맞는 프레임 시간 p95 목표 33.3ms 이하. 데이터 규모와 기기를 고정하여 측정하고, 미달 기기는 품질 조정 후 재측정하거나 지원 범위를 명확히 한다. 다운로드 시간은 별도로 보고한다.
- 최소 20분 연속 재생·반복 탐색에서 크래시/ANR·지속적인 메모리 증가가 없어야 한다. 발열에 따른 품질 조절도 관찰한다.
- 첫 실행에서 새 여행 가져오기 → 자동 지형 준비 → 앱 종료 → 비행기 모드 재실행 → 3D 재생 → MP4 출력이 사용자 수동 파일 작업 없이 통과해야 한다.
- 네트워크 단절/결측/손상 타일/용량 한도/공급자 장애/날짜변경선/도보·차량·비행 전환 및 기존 저장 데이터 회귀를 검사한다.
- 단위 테스트·통합 테스트·실기기 측정과 알려진 제한을 배포 버전에 묶어 기록한다. 에뮬레이터 통과를 실기기 성능 통과로 대체하지 않는다.

## 실행 순서

1. 자동 지형 다운로드·용량 관리·네트워크 문구 수정으로 일반 여행의 사용 흐름 완성.
2. 경로 중복·고도 결측·지형 경계·다리/터널의 예외 처리와 실제 사용자 사례 재현.
3. 카메라·타일 상세도·메모리·오디오 최적화 및 영상/복구 기능 완성.
4. 대표 실기기 검증, 발견된 문제 수정, release 서명과 기존 알파 데이터 전환을 확인한 뒤 정식 배포.

이는 한 파일이나 다운로드 버튼 추가로 끝나는 변경이 아니다. 위 인수 조건을 만족해야 완성품으로 부른다. 구체적인 완료 날짜나 전체 지형 용량은 대상 여행·기기·공급자 측정 전에는 확정하지 않는다.
